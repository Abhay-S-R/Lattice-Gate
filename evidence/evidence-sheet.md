## Measurement record 1: Multi-node revocation propagation and partition bound

Claim: Across 3 independent service-node processes (`A`, `B`, `C`), a device revocation committed at the Control Plane is enforced on every reachable node via ML-DSA-65 signed snapshots, while an isolated node fails closed once its `5,000 ms` freshness lease expires.

Setup and input: Synthetic temporary `KIG_HOME` with `100` active devices + `1` unaffected observer device (`seed = 2026`, `n = 100`) inside the `linux/amd64` offline judging replica (`commit 5410c49`).

Procedure:
1. Run `node scripts/judge.cjs node kig.cjs bench revocation --n 100 --seed 2026 --out /tmp/kig-revocation-bench.json --json`.
2. For each of `100` devices, commit revocation at the CP (`t0 = process.hrtime.bigint()`), push signed snapshot, poll all 3 nodes with signed challenge-authenticated probes until `device_revoked`, and record CP receipt of each node's signed acknowledgement.
3. Verify the unaffected observer device remains `allow` on `A`, `B`, and `C`.
4. Partition Node A via loopback control token, wait `lease_ms + 30 ms`, probe Node A with observer device, then heal Node A.

Expected result: `100/100` revoked devices denied (`device_revoked`) on `A`, `B`, and `C`; observer allowed on all 3 nodes; partitioned Node A denies with `lease_expired` after `5,000 ms`.

Observed result: `100/100` enforced on all 3 nodes; observer allowed on `A`, `B`, `C`. First-denial latency (`ms`): Node A `p50 = 32.75, p95 = 48.30, max = 147.71`; Node B `p50 = 32.67, p95 = 45.83, max = 155.80`; Node C `p50 = 33.68, p95 = 46.13, max = 160.46` (last node `C`). Signed-ack latency (`ms`): Node A `p50 = 23.13, p95 = 35.55`; Node B `p50 = 23.13, p95 = 33.07`; Node C `p50 = 24.58, p95 = 34.58`. Partitioned Node A returned `lease_expired` at the `5,000 ms` bound.

Evidence: [`final-5410c49/bench-revocation.json`](final-5410c49/bench-revocation.json)

Limits: Single host, shared Linux monotonic clock, loopback HTTP (`127.0.0.1`). First-denial timings include signed challenge/response probe overhead and exclude WAN network latency. Revocation is bounded, never instantaneous.
